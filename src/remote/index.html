In Safari, tap Share → Add to Home Screen, enable Open as Web App if shown, then launch the icon. Approve that browser on the PC if prompted. Keep this trusted certificate installed and the PC tray app running on the same private LAN.

Control suspends when iOS locks or backgrounds the app. Reopen it to reconnect; commands are never replayed.

Control help

Touchpad: tap to click, tap twice for a double click, and use two fingers to scroll. Start drag holds the left button; End drag releases it.

Keyboard: focus the target field on your PC. Text sends only when you tap Send text. Lit modifiers stay held until tapped again or released. Text and shortcuts release held input first.
