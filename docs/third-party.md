# Third-party components and build tooling

The self-contained Windows build bundles Microsoft .NET 10.0.12, ASP.NET Core and Windows Desktop runtime components. The release's licenses directory contains DOTNET-LICENSE.txt, DOTNET-ThirdPartyNotices.txt and QRCODER-LICENSE.txt copied from the pinned toolchain/package. QRCoder 1.8.0 uses the MIT license: https://github.com/codebude/QRCoder/blob/master/LICENSE.txt. The mobile build uses pinned Vite/TypeScript tooling; those tools are not required on the installed PC. Exact dependencies are recorded in lockfiles.

Installer compiler: Inno Setup 7.1.0 x64, official immutable release https://github.com/jrsoftware/issrc/releases/tag/is-7_1_0. Download SHA-256 `0362a383ed217d4c4239b5933866dd96d3eb2102737da92f80f6057a4b40df2f`, checked against its official `.issig` and valid Pyrsys B.V. Authenticode signature. Compiler is kept in ignored `.tools/`; no global development tool is replaced. This project's local personal build uses Inno Setup's noncommercial terms. Commercial build/distribution use requires checking/purchasing the appropriate compiler license: https://jrsoftware.org/isdl.php. The generated installer is unsigned; the compiler's signature does not sign the application.

NSIS 3.13 was considered; its download returned HTML rather than a checksum-verifiable ZIP on this host, so it was not extracted or executed. Release tooling uses the verified Inno compiler instead.

Phase 1 adds no shipped third-party dependency and keeps the existing SDK/frontend/QRCoder versions. The shared Host uses the existing ASP.NET Core framework; test runners and CI use Python's standard library (3.13+ for strict TLS). Optional locally downloaded validation tools are not distributed with the application.

## Phase 2 desktop dependencies (2026-10-13)

`PcController.Desktop` pins Avalonia.Desktop and Avalonia.Themes.Fluent **12.1.4** (MIT), with QRCoder **1.8.0** (existing MIT dependency; the shell uses its PNG renderer, not System.Drawing native APIs). `PcController.DesktopTests` separately pins Avalonia.Headless **12.1.4** (MIT); it is test-only. Version selection/support sources and OS baseline decisions are in [desktop-shell.md](desktop-shell.md). The SDK/Node/npm/public Windows version remain unchanged.

Desktop lockfiles record these principal transitive dependencies: Avalonia platform/accessibility packages 12.1.4 and BuildServices 11.3.2 (MIT), SkiaSharp/native assets **3.119.4** (MIT managed binding with native third-party notices), HarfBuzzSharp/native assets **8.3.1.3** (MIT binding with native third-party notices), MicroCom.Runtime **0.11.6** (MIT), Tmds.DBus.Protocol **0.94.1** (MIT), and Microsoft System.Drawing.Common/SystemEvents **6.0.0** (MIT, inherited from QRCoder). Windows ANGLE natives **2.1.27548.20260419** carry their packaged license including BSD notices; they are in Avalonia's cross-platform restore graph, not a new Windows UI migration. NuGet package metadata/licenses were inspected; feed audits report actual results in the roadmap log.

Sources: [Avalonia license](https://github.com/AvaloniaUI/Avalonia/blob/12.1.4/licence.md), [SkiaSharp](https://github.com/mono/SkiaSharp), [HarfBuzzSharp](https://github.com/mono/SkiaSharp/tree/main/source/HarfBuzzSharp), [MicroCom](https://github.com/AvaloniaUI/MicroCom), [Tmds.DBus](https://github.com/tmds/Tmds.DBus). Native redistributions must retain the pinned packages' `LICENSE.txt` and `THIRD-PARTY-NOTICES.txt`, plus .NET and QRCoder licenses and Avalonia/ANGLE notices where shipped. Phase 2 creates no new public distributable; Phase 5 packaging must collect and verify these actual notices, rather than assuming managed MIT licenses cover all native components.

Avalonia BuildServices collects build-time usage metadata by default and has no deployed-app telemetry. Repository Python/PowerShell entry points and CI now set its documented FOSS opt-out (`AVALONIA_TELEMETRY_OPTOUT=1`); set that environment variable for direct dotnet builds too. Initial dependency-selection builds used the vendor default. No Accelerate license or proprietary UI package is used. [Official telemetry source and opt-out](https://github.com/AvaloniaUI/Avalonia.BuildServices).
