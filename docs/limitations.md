# First-release limits

Current public preview: **0.2.1**. It fixes the shared HTTP-budget and late media-authorization issues in 0.2.0; upgrade older builds. Automated dependency/security checks cannot guarantee absence of unknown bugs. Trusted-network, trusted-browser, certificate, and manual acceptance limits below still apply. See [security policy](../.github/SECURITY.md) and [current release evidence](release-evidence.md#version-021--security-hardening-2026-10-12).

- Private IPv4 LAN and signed-in interactive Windows session only. No internet routing, Bluetooth, Wake-on-LAN, screen streaming, file/clipboard transfer, arbitrary commands, simultaneous controllers or native iOS distribution. Version 0.2.0 can open PC-configured executables, set Windows output volume, and request Sleep/Restart/Shut down after confirmation and a 30-second countdown.
- Launcher focus is subject to Windows foreground activation restrictions; if focus is denied, the existing app flashes and the phone advises selecting it on the PC. Launcher buttons do not navigate to a video or start playback automatically. The volume slider controls the current Windows output, separately from app-specific volume; moving it unmutes Windows. Output-device switching is not included.
- Phone power countdowns require the active controller to stay connected and cancel on disconnect, pause, revoke, takeover or server shutdown. Sleep requires Windows hardware/policy support; restart/shutdown allow Windows to ask about unsaved work. Once a request is sent to Windows, cancel any Windows prompt locally. Waking a sleeping PC is not included; reopen the remote after waking it locally.
- Normal privileges cannot control elevated windows, secure desktop or Windows lock screen. Partial SendInput failures release tracked input and pause control. Resolve the target/desktop before resuming.
- One approved browser owns input. iOS can suspend Safari/Home Screen when locked/backgrounded; reopening reconnects. No stale input is queued or replayed. Held-input watchdog is 1200 ms plus scheduling delay.
- Real iPhone 15 Pro / iOS 27 controls, trusted Safari/Home Screen, multi-monitor dragging, US QWERTY Unicode/keys, media profiles and cleanup pass by user report. AZERTY and other devices/layouts remain unverified. Smooth responsiveness is subjective; numerical finger-to-cursor latency has not been measured. RTT is not input latency.
- Media chords require the matching focused player/default hotkeys. General uses the active Windows media session/system volume. YouTube previous requires a playlist; Stremio Next requires another episode and has no supported Previous shortcut. Seek duration can vary with player settings. External Stremio players require their matching profile.
- Per-installation CA trust requires explicit iPhone profile installation/full trust. Never bypass a warning as acceptance. Root expiry/replacement requires new trust. Address changes keep the root and renew leaf SANs, but phone bookmarks must use the new IP.
- No installer/application code signing is configured. Windows warnings are possible. Current-account tests do not prove clean-account/VM installation, reboot or uninstall. Record those actual tests before marking release acceptance complete.

- Development Phase 1 provides a portable shared backend and isolated macOS/Linux loopback tests. It does not add a usable Mac/Linux companion, native input, protected production storage, desktop UI or LAN trust setup. The published release remains Windows-only; see [Phase 1 scope/evidence](../MULTIPLATFORM_PLAN.md#execution-log).

## Phase 2 development shell

A source-built Avalonia macOS/Linux shell and platform-aware browser are available for development. The normal shell reports setup-required and has no HTTPS listener until Keychain/keyring storage and real platform services exist. Approval/pause/revoke workflows can be checked with the separate loopback fixture; they do not establish native input, physical-phone, GNOME Wayland, LAN or installed acceptance. Network identity/notification coverage needs platform acceptance before a production factory is enabled. [Desktop shell guide](desktop-shell.md) documents dependency baselines, window/tray fallback and commands. Public downloads remain Windows 0.2.1.
